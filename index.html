4-stage NLP pipeline used to analyze every review in the Amazon Fine Food dataset.
1
Text Preprocessing
HTML tags stripped, text lowercased, punctuation removed. Tokens extracted via NLTK word_tokenize. Stopwords removed using NLTK corpus. Words lemmatized to base form using WordNetLemmatizer.
clean_html()word_tokenize()stopwordsWordNetLemmatizer
2
POS Tagging
Each token tagged with Penn Treebank POS label (NN, VB, JJ...) using NLTK averaged perceptron tagger. Adjectives (JJ), nouns (NN) and verbs (VB) extracted separately for feature analysis.
pos_tag()JJ → adjectivesNN → nounsVB → verbs
3
Chunking + NER
RegexpParser extracts Noun Phrases and Verb Phrases from POS-tagged sequences. spaCy en_core_web_sm adds Named Entity Recognition (ORDINAL, CARDINAL, ORG, PRODUCT) and dependency parsing.
RegexpParserNP chunksVP chunksspaCy NER
4
Sentiment Analysis
VADER scores compound, positive, negative, neutral values. TextBlob gives polarity (−1→+1) and subjectivity. Ensemble majority vote between both. Sentence-level scoring applied to each sentence individually.
VADER SIATextBlobEnsemble voteSentence-level
